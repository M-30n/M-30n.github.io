# Game Portal

A small collection of fan-hosted retro football games you can play right in your browser, no install needed.

**Play it here:** [m-30n.github.io](https://m-30n.github.io/)

## Games

| Game | Folder | Notes |
| --- | --- | --- |
| Retro Bowl College | `/RetroBowl-College/` | Manage your school team, recruit stars, and build a collegiate dynasty |
| Retro Bowl | `/RetroBowl/` | The classic football management game, with a built-in mod menu |
| Madden NFL 07 | `/Madden/` | Game Boy Advance version, run in the browser |
| Madden NFL 06 | `/Madden/` | Game Boy Advance version, run in the browser |

## Retro Bowl mod menu

A fan made version of Retro Bowl with a built in mod menu.

### Features

- In game mod menu
- Coaching credits editor
- Salary cap editor
- Fans editor
- Roster limit control
- Draft picks for all rounds
- Facilities max / reset
- Export and import saves as JSON
- Optional starter save on first launch
- Unlocked full version / no nag walls in the web build

### Mod menu controls

- Click **MOD MENU** to open the mod menu
- **X** closes it
- **/** hides or shows the entire mod menu
- Apply a value, then the game reloads so changes stick

### Starter save

On first visit you can load `saves/starter.json`, a pre built save with high credits, salary, facilities, and roster content.

## Madden 07 controls

Click the **Controls** button under the player for the full list of what each button does on offense and defense. Default keyboard layout:

| GBA button | Key |
| --- | --- |
| D-Pad | Arrow keys |
| A | `Z` |
| B | `X` |
| L | `Q` |
| R | `E` |
| Start | `Enter` |
| Select | `V` |

Keys can be remapped from the settings icon in the player's toolbar, and gamepads are supported.
